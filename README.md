## 5 features of **Gadget Heaven** :

- 1. Product Listing - Display of gadgets with detailed information.
- 2. Category Filtering - Filter gadgets by category.
- 3. Add to Cart - Option to add gadgets to a shopping cart with stock availability checks.
- 4. Wishlist - Save products to a wishlist with the ability to remove items.
- 5. Add from Wishlist to Cart - Add wishlist items to the cart directly.
